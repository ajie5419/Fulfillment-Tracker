# 计划日期 FS 修复验收

## 边界与规则

- 分支 `fix/plan-fs-dates`，基于 `7654bc1`；独立 worktree 与依赖。未改 sandbox、3110 服务、运行配置、QMS 或数据库。
- 草稿允许保留冲突日期，并在保存结果及查询 DTO 返回 `dateConflicts`。发布在计划锁之后、写基线及确认待办之前，重新读取事务内事实并校验；阻断项返回 409 并回滚。发布 API 原有可见性及操作权限检查保留。
- Finish-to-Start：最早开始是前置预计完成的次日；若该日为配置停工日，继续后移。周末不自动排除。原计划开始到完成的自然日跨度保持不变，不将工期自动改成工作日。
- 多前置取最晚约束；子节点影响汇总，再传递后续。已完成节点保留实际完成日，不为满足依赖而改写事实，历史矛盾提示核实。
- 有依赖但无开始日的旧记录返回 `MISSING_START`，预测仅作参考，不能以兼容兜底宣称交期正常。无依赖且无开始日不新增发布限制。
- 任何日期冲突使有效预计交期、拖期结论及余量为空，并明确显示待核实；节点参考预测仍保留。正常并行不因未连接末节点而新增冲突，交付仍按末一级节点定义。
