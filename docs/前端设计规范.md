# 前端设计规范

2026-10-21 定稿。以后无论改后端还是加功能，页面都按本规范做。电脑端用下面第 1 节的组件；手机端 `/m`（vant）见第 6 节。
参考风格：中性灰白 + 单一强调色（主色蓝），卡片细边框、不用阴影，卡片里再套浅灰区域放图表和列表。

## 1. 先用现成的，不要在页面里重新画

| 要做的东西 | 用这个 | 说明 |
|---|---|---|
| 整页框架（侧栏、页头、滚动） | `layouts/default.vue` | 新页面只写内容区；菜单加在 `groups` 里，图标在 `UiNavIcon` 里补一个路径 |
| 分区卡片 | `UiSectionCard`（title / sub / #extra） | 页面里所有分区都用它；表格类老页面用 `a-card`，`base.css` 已统一成同样外观 |
| 顶部指标 | `UiStatCard`（label / value / unit / tone / to 或 clickable） | 标签前自动画细色条；`unit` 可放一句短说明（如"占 98%"）；整排用 `.ft-stats` / `.ft-stats.cols-3` 或页面自己的 grid |
| 卡片里的浅灰区域 | `<div class="ft-well">`，列表用 `<div class="ft-well list">` | 图表、列表都放在里面 |
| 列表行 | `UiListItem`（tone / icon / compact，插槽 #title #desc #meta #extra） | 左边状态图标块，右边放 `UiStatusTag` 或数字 |
| 柱状图 | `UiColumnChart`（items: key/label/value/to，highlight） | 最大的一根高亮，其余斜纹灰 |
| 占比 | `UiDonut`（segments: key/label/value/tone/to，caption） | 中间合计，右边图例 |
| 横条排行 | `UiBarList` | 如"按责任部门" |
| 状态标签 | 新代码用 `UiStatusTag tone="late"`，文字必填 | 旧代码里的 `a-tag color="red"` 等 Ant 具名色已由 `base.css` 统一映射成同样的状态色胶囊（红→延误、橙/金→风险、绿→完成、蓝/青/紫→主色，不带颜色→中性灰），不必逐个改 |
| 状态小图标 | `UiStatusIcon` | 形状本身区分状态 |
| 标题旁的说明 | `UiHelpTip` | 大段说明文字收进去，不要直接铺在页面上 |
| 刷新 | `UiRefreshButton` | 只有图标 |
| 筛选 | 工具栏放 1～2 个最常用的；其余放 `UiFilterButton`（count / @clear）里，一行一个 `.ft-filter-row`，分组标题 `.ft-filter-group`；生效条件用 `UiFilterChips` 显示在工具栏下面 | 例子：`pages/risks.vue` |
| 视图 / 状态切换 | `a-segmented` | 不要再用实心蓝的 `a-radio-group button-style="solid"` |
| 卡片里的表格 | `a-table` 加 `class="ft-table"` | 表头无底色、首尾列留 20px |
| 卡片标题 + 说明 | `<span class="ft-title">标题 <UiHelpTip>…</UiHelpTip></span>` 放在 `a-card` 的 `#title` | |
| 卡片内工具栏 | `<div class="ft-toolbar">` 左边状态切换，`<div class="ft-toolbar-right">` 放搜索、次要筛选、`a-segmented :options="LAYOUT_OPTIONS"` | 例子：`pages/purchases.vue`、`pages/drawings.vue` |

## 2. 颜色与文字

- 颜色只用 `app/assets/base.css` 里的 `--ft-*` 变量；状态色唯一来源是 `shared/status.ts`。**页面和组件里不新增十六进制颜色。**
- 一个页面只有一个强调色（主色蓝）：主要按钮、链接、选中态。红 / 黄 / 绿只表示状态。
- 状态永远同时给文字（或图标），不能只靠颜色。状态色当文字用时用深一档的 `--ft-*-text`。
- 文字对比度 ≥ 4.5:1：次要文字用 `--ft-text-2`；`--ft-text-3` 只用于不重要的辅助信息，不放在灰底上。
- 字号：页面里卡片标题 16px/600，正文 14px，辅助说明 12～13px，指标数字 24px/600。

## 3. 版式

- 卡片：白底、1px `--ft-border` 细边框、圆角 `--ft-card-radius`，不加阴影。卡片之间 16px，卡片里控件之间 8px。
- 卡片标题行：左边标题（+ `UiHelpTip`），右边是切换、常用筛选、刷新、主按钮，**一行放完**。
- 一屏内容按"指标 → 图表 → 明细"从上到下；左右两列时用"左宽右窄"（7 : 5）且两列各自往下排，不留空洞。
- 表格列宽按内容收紧，1440 宽屏幕上不要横向滚动；操作列固定在右边。
- 不做没有数据支撑的东西：环比、目标完成率、假筛选、假搜索框都不做。

## 4. 新页面 / 新功能自查

1. 有没有在页面里手写卡片、图表、列表行、筛选面板（手机端：卡片、标签）？有就换成上面的组件，缺的先补成通用组件再用。
2. `git diff -U0 | grep -E '^\+.*#[0-9a-fA-F]{3,8}'` 不应出现新的颜色值（`base.css` 变量定义除外）。
3. 状态都有文字；可点的元素能用 Tab 聚焦且有焦点框。
4. 1440 和 390 两个宽度各看一遍：不横向滚动、不截断关键文字。
5. `pnpm typecheck`、`pnpm test`、`pnpm build` 通过。
6. 没有给 `a-empty` 传 `:image="null"`：当前 Ant Design Vue 版本渲染时会报 `Cannot use 'in' operator to search for 'type' in null`，整块显示空白（10-26 在生产管理页展开"没有流转记录"的工序时踩到）。卡片、抽屉里的小号"暂无"直接写一行灰字 `<p>`。
7. 筛选条件记在地址栏（`?wo=` 等）的页面，除了"本地改了写回地址栏"，还要 `watch(route.query)` 反向同步：页面没离开时点了全局搜索或提醒里的同页链接，Nuxt 不会重建页面，只改地址栏，不同步就会停在旧工单 / 旧筛选（10-26 生产管理、车间看板、采购页都踩到）。带一次性定位参数（`?part=`、`?id=`、`comments=1`）的，关抽屉 / 弹窗时要清掉，否则再点同一条提醒没反应。

## 5. 已知例外

- `UiStatusIcon` 里图标内部的白色笔画、侧栏 logo 的白色对勾是图形本身的颜色，保留。

## 6. 手机端（/m，vant）

- 颜色同一套 `--ft-*`；vant 的 `--van-*` 主题变量和标签样式在 `app/assets/mobile.css` 里统一映射，页面里不写颜色值。
- 卡片用 `components/m/Card.vue`（白底、细边框、状态图标，不用左侧色条和阴影）；分组标题 `.m-section`，提示条 `.m-hint`，卡片内排版 `.m-row` / `.m-title` / `.m-desc` / `.m-meta`。
- 状态标签用 `van-tag type="danger|warning|success|primary"`，样式已是带色点的胶囊；大号可点的选项标签（`size="large"`）不带色点。
- 顶栏白底、不用渐变色块；底部页签照旧。版式按手机习惯来，不照搬电脑端的多列布局。
