## 四、改什么动哪一部分

每个 .vue 文件分三段：

- `<template>`：页面上看得到的东西。改文字、按钮、表格列以外的布局，都在这里。
- `<script setup>`：逻辑。表格列定义（如 `{ title: '级别', ... }`）通常写在这里，改列名、增减列在这里；按钮点了做什么也在这里。
- `<style>`：颜色、间距、宽度。

具体：

- 改文字：先在页面文件里搜原文字；搜不到就去它用到的弹窗组件（见第一节最后一列）里搜。
- 改按钮：按钮本身在 template；点击后的动作在 script。如果按钮要调用新接口，就要动后端 server/api/，不再是纯前端改动。
- 改布局：template 调结构，style 调尺寸和颜色。

## 五、改完怎么在本机看效果

- 代码确认：本机启动命令是 `pnpm dev`（README"本地启动"一节），地址 https://localhost:3100；`pnpm dev` 即 `nuxt dev`。
- 框架行为（未在 zhao 本机实测）：`nuxt dev` 下保存 .vue/.css 文件，浏览器会自动刷新到新效果，不用重启；改 nuxt.config.ts 时它会自己重启一次。
- 如果本机是用 Docker 镜像（Dockerfile / docker-compose.yml）跑的，就没有热更新，每次改完要重新构建。本机实际用哪种方式跑，我这次没登到本机核实。
- 登录履约前需要先跑起 QMS 前端（QMS 目录里 `pnpm dev`），否则登录页打不开。
- 手机端效果：电脑浏览器打开 https://localhost:3100/m 即可，开发者工具切成手机尺寸更接近真实效果。
