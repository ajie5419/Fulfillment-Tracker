### 主要变化
- **侧栏**：白色圆角卡片悬浮在底色上，每项前有线条图标（新组件 `UiNavIcon`，内联 SVG，不引图标库）；选中项浅蓝底 + 蓝字；未读角标改浅蓝胶囊；品牌区加副标题"项目履约与异常管理"。
- **底色**：电脑端改为淡蓝灰 `#f3f6fb`。
- **统计卡 chip**：顶部"圆形图标 + 标签"，下面 30px 深色数字；细边框。
- **领导总览**：标题 22px，副标题"本周从…起，数据与看板同源"；表格行高加大；"其中超期""源头延误"大于 0 用红色胶囊，0 用灰色数字；分区卡片加细边框。

### 和任务单 v2 写法不同的 3 处（实现中发现，按更稳的做法改了）
1. **底色没改 `:root` 的 `--ft-page-bg`**，而是在 `.ft-app { --ft-page-bg: #f3f6fb; }` 里覆盖。原因：手机端 `mobile.css` 的 `--van-background` 也引用这个变量，改 `:root` 会让手机端底色跟着变。`html, body` 的背景因此也保持原值。
2. **侧栏外框 212px（左 12px 留白 + 200px 卡片），宽屏时内容区左内边距从 24 缩到 12。** 第一版按任务单做成 252px，采购页的表格被挤窄，最右"进度"列被固定列盖住。现在内容区起点和原来一样（200 + 24 = 212 + 12），各页面表格宽度不变。
3. **菜单项高 36px（任务单写 40px）**：40px 时 900 高的屏幕放不下全部菜单，"演示工具"要滚动才看得到；36px 含间距与原来一样，一屏放下。
另外，总览页两组统计卡在屏幕 < 1680 宽时上下排列（并排时每张卡太窄，"本周新增异常"会被截断）。
