# 项目总览：全盘统计合并与双端下钻

## 功能边界

- PC 移除平级「项目全景」菜单，在 `/board?view=panorama` 提供「全盘统计」。原工单看板和驾驶舱保留，驾驶舱仍要求 `can.overview`。
- `/panorama` 保留兼容跳转，电脑进入上述统计页签，手机进入 `/m/board?view=panorama`；查询参数（含空分组）、数组参数及锚点保留，仅视图参数替换为统计。
- 手机工作台增加「项目总览」入口，使用 Vant 统计行、分组及工单卡片，并提供「全盘统计 / 工单清单」页签；底部原「异常」入口不变。
- 工单详情继续沿用 `/wo/:no`，不建立新单项目业务域。手机不新增独立详情页，也不新增手机预警处理模块；手机下钻异常沿用 `/m/issues` 的现有处理权限。
- PC 工单行进入 `/risks?wo=...&tab=all&dept=0`，手机进入 `/m/issues?workOrderNumber=...&tab=all` 的未关闭异常清单。两端带 `returnTo`，返回统计时保留原筛选。异常数字明确仅表示未关闭异常事项，而非工单全部风险。

## 数据与权限

不新增 API、数据写入或数据库迁移。统计及工单清单从同一次 `/api/board?closed=1` 响应产生；接口继续使用原 `getScope` / `scopeWorkOrders` 可见范围。`/api/panorama` 继续兼容，改为引用同一个 shared 聚合函数。

统计、分组、清单共用 `shared/panorama.ts` 的分类口径：

- 在制：状态 `IN_PROGRESS`；正常：绿色在制；有风险：非绿色在制。
- 已完工：`COMPLETED`；未开工：`OPEN`；取消工单不计数。
- API 获取含已关闭的数据用于已完工计数，分组数只算在制。空经理 / 空产品线可单独下钻。
- 有风险在制工单数不是预警数或异常事项数，正常 / 风险清单不混入 OPEN、COMPLETED。
- 未验收始终标记「待接入」，不显示伪造的 0。加载中显示「—」，错误提供重试，不把失败呈现为空清单。

## 自动化验收

- 聚合与下钻逐统计卡、逐项目经理 / 产品线数字一致，包括空分组、取消、完工、未开工、空可见范围。
- 两端统计组件：加载、空数据、失败重试、分组点击、工单处理链接、返回条件。
- 旧页面真实组件执行电脑 / 手机 replace 跳转并保留参数。
- 手机页签与 URL / 回退同步；异常切页签、打开详情及同页工单参数变化不丢上下文。
- PC 页签、普通角色统计入口、管理角色驾驶舱入口，保持权限差异。
- 最终结果以 PR 验收记录中的实际命令输出为准。

## 尚需真实页面验收

本 PR 代码不加载到当前主目录 3100 服务。浏览器检查时侧栏停留在独立的 QMS 登录页；本次没有为工作树另配已认证运行环境，也未伪造会话或改动主服务。因此没有声称完成 PR 版本的真实登录态 1440 / 390 宽度验收；已完成的是双端组件自动化测试和生产构建。

部署或在安全的独立已认证预览环境加载本分支后，还需检查：

1. 1440 / 390 宽度的文字换行、键盘焦点、长工单号及横向溢出。
2. 实际不同角色下的可见范围、经理 / 产品线下钻与页面数字。
3. 风险工单进入对应处理页后工单筛选、返回原条件，以及旧链接手机跳转。

不需要创建、修改或关闭业务数据即可完成这些页面检查。
