# 履约系统权限方案（v0.1 待 zhao 确认，2026-10-19）

现状见 [角色与可见范围现状.md](角色与可见范围现状.md)。

## 原则

- 不做通用的"权限矩阵"或"自定义角色"配置器。之前的系统就是规则做得太细、跑不起来。
- 角色固定为下面 8 种。每种角色能看什么、能做什么写死在代码里，改规则走开发。
- 设置页只做两件事：
  1. 给人指定角色（就是现有的"通知对象"，改名为"人员与角色"）；
  2. 把 QMS 部门对到 6 个业务部门，只配一次。
- 后端统一拦截，不只是藏按钮。

## 一、身份怎么确定

| 角色 | 怎么确定 | 变化 |
|---|---|---|
| 管理员 | 服务器配置（不变） | 不变 |
| 领导 | 设置页指定（现有"分管领导"） | 不变 |
| 项目部负责人 | 设置页指定 | 不变 |
| 项目经理 | 每个工单指定 | 不变 |
| 部门负责人 | 设置页指定，部门改为**下拉选择**（技术/采购/生产/质量/财务/项目部） | 改：不再手填部门名 |
| 外协专员 | 设置页指定 | 不变 |
| 财务 | 设置页指定 | 不变 |
| 部门员工 | **自动**：QMS 里的所属部门 → 对应的业务部门 | 新增：设置页加一张"QMS 部门 → 业务部门"对照表（班组、科室都对到大部门；没对上的算"其他"） |

一个人可以有多个角色，权限取并集。

## 二、能看到什么

| 角色 | 工单范围 | 电脑端菜单 | 付款金额 | 专属页面 |
|---|---|---|---|---|
| 领导、项目部负责人、管理员 | 全部 | 全部 | 能看 | **领导总览**（新增，见第四节） |
| 项目经理 | 只看自己负责的工单 | 全部 | 能看（自己的工单） | — |
| 技术部 | 全部 | 每日 + 技术 | 不能看 | — |
| 采购部 | 全部 | 每日 + 采购 + 齐套 | 能看 | — |
| 生产部、外协专员 | 全部 | 每日 + 生产 + 发放签收 | 不能看 | — |
| 质量部 | 全部 | 每日 + 生产（只读） | 不能看 | — |
| 财务 | 全部 | 每日 + 付款申请 | 能看 | — |
| 其他部门 | 全部 | 每日 | 不能看 | — |

说明：
- 别的部门的页面只是不在菜单里显示。从提醒链接点进去仍然能看，只是改不了。这样可以避免"提醒点开是 403"。
- 手机端 5 个页签不变，因为都是现场动作。"发出"页签只给生产部和外协专员显示。
- "我的提醒"和每日汇总不变，本来就是按人发的。

## 三、能做什么（新收紧的用 ★ 标出）

| 操作 | 谁能做 |
|---|---|
| ★ 建/改/删出图任务、建/作废发放单 | 技术部、管理员（作废仍限发放人或管理员） |
| ★ 建/改/删采购行、Excel 导入、手工标到货/撤销 | 采购部、该工单项目经理、管理员 |
| ★ 提付款申请 | 采购部、该工单项目经理、管理员 |
| 付款标已付/暂缓 | 财务、管理员（不变） |
| ★ 建/改/删工件和工序、导入 BOM、套模板、处理待确认匹配 | 生产部、外协专员、该工单项目经理、管理员 |
| ★ 开工/完工/发出/返厂 | 生产部、外协专员、该工序责任人、管理员 |
| 装配节点 | 生产经理、该工单项目经理、管理员（不变） |
| 上报异常 | 所有人（不变） |
| 受理/处理/改派/关闭异常 | 不变（按责任人、部门负责人、项目经理、项目部负责人） |
| 签收、确认变更影响、标记出图 | 不变（只能处理发给自己的） |
| 设置、模板 | 仅管理员（不变） |

## 四、领导总览（新页面）

只放一屏，数据和看板同源，不做新的统计口径：
- 顶部数字：红/黄/绿工单数、本周新增异常数、本周关闭异常数、超期异常数
- 卡在哪个环节：设计出图、采购到货、外协返厂、齐套、异常处理，各自超期了多少项，点进去看明细
- 按部门：各部门名下未关闭异常和超期数量（按责任部门统计）
- 红色工单清单：工单号、项目经理、交期、主要原因
