# 设计改版试点任务单 v2（方向 A：浅色悬浮侧栏 + 淡蓝灰底 + 卡片流）

项目：`~/代码/Fulfillment-Tracker`（Nuxt 3 + Vue 3 + ant-design-vue 4.2.6）
依据：v1 试点结果用户评价"不好看"，2026-10-21 给出参考图（FreightPro 物流看板），并选择方案 A：连侧栏和底色一起改。
性质：仍是试点。整体框架（侧栏、页头、底色）全站生效；页面内容只改领导总览。不提交、不推送，等用户看效果。

---

## 1. 和 v1 的区别

| | v1（已做，留在工作区） | v2 |
|---|---|---|
| 侧栏 | 不动（深色） | 改为浅色悬浮侧栏，带菜单图标 |
| 页面底色 | 不动 | 改为淡蓝灰 |
| 统计卡 chip | 方形图标块、数字跟随状态色 | 圆形图标、数字统一深色、更大留白 |
| 表格 | 浅表头 | 浅表头 + 行高加大 + 状态数字改胶囊 |
| 其他页面 | 完全不变 | 只有侧栏、页头、底色跟着变；页面内容不变 |

v1 的 `UiStatusTag`、`.ft-table`、两个主色 token 保留，在此基础上改。

## 2. 设计规格（对照参考图）

### 2.1 底色与页头（全站电脑端）
- `--ft-page-bg` 由 `#eef1f5` 改为淡蓝灰 `#f3f6fb`（**这是本次唯一允许改的已有变量值**；`html, body` 的 `#f5f6f8` 同步改为 `var(--ft-page-bg)`）。
- 页头（用户名 + 退出）保留原位置和功能，背景改为与底色同色的半透明，不加搜索框、不加通知铃（没有对应功能，不做假入口）。
- 手机端 `/m` 用的是另一套布局，不受影响，需截图证明。

### 2.2 侧栏（`layouts/default.vue`）
- 白色卡片，悬浮在底色上：外边距 16px，圆角 16px，细边框 `var(--ft-border)`，极淡阴影（复用 `--ft-card-shadow`）。宽度 220px。
- 品牌区：现有勾选 logo + "项目履约"，文字改为深色 `var(--ft-text)`，下面加一行小字副标题"项目履约与异常管理"（`var(--ft-text-2)`，12px）。
- 分组标题：12px，`var(--ft-text-2)`。（参考图用的是更浅的灰，但 `--ft-text-3` 在白底上只有约 3.1:1，达不到 4.5:1，所以用 `--ft-text-2`。）
- 菜单项：高 40px、圆角 10px、文字 `var(--ft-text-2)`、14px；左侧 18px 线条图标（颜色随文字）。
  - 悬停：背景 `var(--ft-fill)`。
  - 选中：背景 `var(--ft-primary-bg)`，文字和图标 `var(--ft-primary-text)`，字重 500。
- 未读角标：改为浅蓝胶囊（背景 `var(--ft-primary-bg)`、文字 `var(--ft-primary-text)`），与参考图一致；仍带 `aria-label`。
- 窄屏（< lg）收起、"菜单"按钮展开、`inert`、焦点框等现有行为全部保留。
- 图标：新增 `app/components/ui/NavIcon.vue`，内联 SVG 线条图标（`stroke="currentColor"`，不写颜色值），覆盖现有 14 个菜单项。**不引入图标库**（`@ant-design/icons-vue` 不是直接依赖，加依赖要改 `package.json`，禁止）。

### 2.3 统计卡 chip 样式（`StatCard.vue`，只改 `chip` 分支）
- 布局改为：顶部一行"圆形图标 + 标签"，下面大数字，再下面补充说明。
- 图标：40×40 圆形，背景 `var(--ft-{tone}-bg)`，图标 20px、颜色 `var(--ft-{tone})`。
- 数字：30px、字重 500、颜色统一 `var(--ft-text)`（不再用红字；状态靠图标形状 + 颜色 + 标签文字表达）。
- 卡片：内边距 20px 24px，细边框 `var(--ft-border)` + 现有阴影。
- 不传 `chip` 的卡片（另外 7 处使用）**外观和行为必须不变**。
- 仍不做"环比涨跌"（没有数据，不编数字）。

### 2.4 领导总览（`overview.vue`）
- 顶部：标题 22px/600 + 副标题"本周从…起，数据与看板同源"；刷新按钮在右侧。
- 两组统计卡（工单状态 / 异常）和"卡在哪个环节"保持 v1 的分组和跳转，换用 2.3 的样式。
- 表格：`size="middle"`（行高加大）；"其中超期"、"源头延误"大于 0 时用 `UiStatusTag tone="late"`（文字如"1"），等于 0 时普通灰色数字；拖期列沿用 `UiStatusTag`。
- 表格不加筛选胶囊（参考图里的 All / Loaded 筛选对应它的业务状态，总览的几张表没有可筛的状态，不做假筛选）。
- 数据绑定、权限、接口、刷新、错误提示、加载状态不变。
