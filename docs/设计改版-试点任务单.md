性质：只做试点（1 个页面），验收通过后再决定是否推广。
执行者：独立实现会话。规划与最终审核由主会话负责。

## 1. 目标

把 `app/pages/overview.vue`（领导总览）改成参考图 1 的风格：
统计卡带浅色图标块、状态用带圆点的胶囊标签、表格用浅色表头、分区用统一卡片。
同时沉淀出 3 个可复用的基础件，为后续推广做准备。

## 2. 已确认的现状事实（实现者不必重新调研）

- 全站已有两轮改版成果：`UiStatCard`（7 处使用）、`UiSectionCard`（5 处使用）、`UiStatusIcon`、`.ft-page`、`.ft-stats` 等。
- **`overview.vue` 没有用这些基础件**：它直接用 `a-card`、`a-statistic`、`h3`，且 `.muted` 写死 `#999`。这是最不统一的页面，所以选它做试点。
- 状态色唯一来源是 `shared/status.ts` 的 `STATUS_COLOR`；`app/assets/base.css` 里的 `--ft-*` 与之同值（两处手工同步）。**本次试点不改这两处已有的值。**
- 全项目 `a-tag` 出现在 19 个文件、`van-tag` 12 个、`a-table` 16 个。标签颜色多为 Ant 具名色（`red`、`orange`），没走状态 token。**本次试点不批量替换，只新增组件并在 overview 使用。**
- 项目约束（来自 `base.css` / `status.ts` 注释）：状态**永远同时给文字或图标，不能只靠颜色**；状态色做文字时用深一档，对比度目标 ≥ 4.5:1。
- 现有代码里已出现但未成变量的值：`#e7f0fb`（4 次）、`#1d5fae`（5 次）。本次把它们提升为 token。

## 3. 设计规格

### 3.1 新增 token（只在 `base.css` 的 `:root` 追加，不改已有值）
```
--ft-primary-bg:   #e7f0fb;
--ft-primary-text: #1d5fae;
```

### 3.2 新增组件 `app/components/ui/StatusTag.vue`（自动导入名 `UiStatusTag`）
- props：`tone: 'late'|'risk'|'done'|'upstream'|'none'|'primary'`；默认插槽为文字（**必填，不可为空**）。
- 外观：高 22px、左右内边距 10px、圆角 999px、字号 12px、字重 500；左侧 6px 圆点。
- 颜色：背景 `var(--ft-{tone}-bg)`，文字 `var(--ft-{tone}-text)`，圆点 `var(--ft-{tone})`。
  - `none` 文字用 `var(--ft-text-2)`；`primary` 用 3.1 的新 token。
- 不允许在组件里写十六进制颜色。

### 3.3 扩展 `UiStatCard`（向后兼容，默认行为不变）
- 新增可选 prop `chip?: boolean`，为 true 时：标签左侧显示 36×36、圆角 10px 的图标块，背景 `var(--ft-{tone}-bg)`，内放 `UiStatusIcon`（颜色 `var(--ft-{tone})`）；同时隐藏顶部色条。
- 现有 7 处使用 `UiStatCard` 的页面**视觉和行为必须不变**（不传 `chip` 即不变）。
- 不做"环比涨跌"：后端没有这类数据，**禁止为此新增接口或编造数字**。

### 3.4 表头样式（只对 opt-in 的表格生效）
在 `base.css` 新增类 `.ft-table`，**不要写成全局选择器**（会影响另外 15 张表）：
```
.ft-table .ant-table-thead > tr > th { background: var(--ft-fill); color: var(--ft-text-2); font-weight: 500; font-size: 13px; }
.ft-table .ant-table-thead > tr > th::before { display: none; }   /* 去掉列分隔竖线 */
.ft-table .ant-table-tbody > tr:hover > td { background: var(--ft-fill); }
```

### 3.5 `overview.vue` 改造
保持**全部数据绑定、权限判断、接口调用、刷新按钮、错误提示、加载状态不变**，只换展示层：

| 现状 | 改为 |
|---|---|
| 最外层 `a-card title="领导总览"` | `.ft-page` 容器 + 顶部标题行（标题 + 副标题"本周从…起" + 刷新按钮） |
| 6 个 `a-statistic`（红/黄/绿工单、本周新增/关闭/超期异常） | 分两组 `UiStatCard`（各 3 张，`.ft-stats.cols-3`）：「工单状态」红(late)/黄(risk)/绿(done)；「异常」新增(primary)/关闭(done)/超期(late，数量为 0 时 tone 用 none)。全部 `chip`，保留原跳转 `to` |
| "卡在哪个环节"的 `a-card hoverable` | `UiStatCard`：`count>0` 用 late，否则 none；保留 `s.link` 跳转 |
| 4 张表上方的 `h3` | 每张表放进 `UiSectionCard`（`padding="none"`，用其 `title`），表格加 `class="ft-table"` |
| 表格里"未关闭异常/源头延误"的数字 `.warn` | 保留 |
| `.muted { color:#999 }` | 改用已有 `ft-muted` 或 `var(--ft-text-3)` |
| 红色工单表 | 在"项目经理"列旁不新增列；工单列沿用 `WoLink` |
| 预计拖期表的"拖期 N 天" | 用 `UiStatusTag tone="late"`，文字为 `N 天` |
