# 共用列表与组件复用

## 实施边界

首批接入采购电脑页、手机到货列表及付款申请的关联物料选择。复用已安装的 Ant Design Vue、Vant 和 Nuxt，不增加组件库或请求库。

| 能力 | 实现 | 业务页保留的职责 |
| --- | --- | --- |
| 电脑分页 | `UiListPager` 包装 `a-pagination` | 路由参数、筛选、列和操作 |
| 手机追加 | `UiLoadMoreList` 包装 `van-list` | 卡片、筛选和详情跳转 |
| 分页请求 | `usePagedList` 使用 Nuxt `useAsyncData`、`useRequestFetch` | 资源地址、筛选身份、追加或替换模式 |
| 远程选料 | 现有 `a-select` 远程搜索及滚动事件 | 工单范围、已选项回填和提交校验 |

公共请求层只维护当前筛选下成功页面的追加结果，不增加预取、自动重试或另一套请求缓存。请求身份包含筛选、页码和每页条数；筛选切换后旧响应不能混入新列表。失败保留已追加结果，重试同一页。第二个远程选料入口接入时再提取选择组件。

## 接口契约

`GET /api/purchases` 保留原有筛选和权限，增加 `page`、`pageSize`，默认分别为 1、50。两者必须为正安全整数，每页最多 100 条，偏移量也必须为安全整数。返回：

```ts
{ rows, total, page, pageSize, stats, groups }
```

- `total` 是当前权限和筛选范围的匹配数，`rows` 仅为本页。
- 请求页超过末页时返回实际末页；空结果返回第 1 页。
- 全局顺序为未到货、已到货、已取消；未到货与已取消按需求日、创建日、ID 升序，已到货按到货日降序、ID 升序。先确定全局顺序，再读本页，避免先取前 500 条再局部排序。
- `stats` 沿用原有范围：受可见工单和所选工单影响，不受列表状态及搜索词影响。
- `groups` 只返回本页涉及的工单，但按完整筛选结果计算数量与到货进度。组标题同时显示本页和匹配总数，取消项不计入进度分母。

`GET /api/purchases/options` 要求 `workOrderNumber`，支持相同分页参数、`q` 远程搜索及 `ids` 已选项回填（最多 50 个）。仅返回 ID、工单、物料名、规格、供应商名和需求日，排除已取消项。工单及可见范围同时校验，不返回付款金额。付款提交仍由原有服务重新校验权限、状态、同工单约束及 50 项上限。

本批不修改数据库结构。分页是实时查询，没有跨请求快照；数据被新增、删除或重新排序时，刷新可重新取得当前结果。手机追加按 ID 去重。深页仍使用数据库偏移查询，后续应根据真实查询耗时决定索引或游标方案。

## 页面行为

- 电脑页统一使用服务端本页数据，关闭表格内部的第二次分页。筛选、搜索、页码和每页条数保存在地址栏；筛选或条数变化回到第一页。
- 翻页保留勾选及物料信息；工单、状态或关键词改变才清空勾选并提示，最多选择 50 项。
- 手机每次读取 20 项，提供触底加载及手动加载入口。首屏失败、后续页失败和真正空结果分别显示；详情返回保留已加载列表和滚动位置。
- 付款选择不再把前 500 项当成全量。搜索在服务端执行，已选记录单独按 ID 回填，翻页或搜索不会静默丢弃已选项。

## 后续批次

1. 将付款列表、发放签收、设计、工艺、齐套及相关选项接入同一分页契约，逐个保持业务排序、权限和统计口径。异常列表及风险汇总依赖完整结果，不直接改成只读一页。
2. 优先复用 `a-form` / Vant Form 统一表单校验；保留项目业务规则及服务端校验。
3. 检查手机卡片等交互元素的键盘、点击及状态表达，优先采用现有组件能力。已有项目卡片、状态标签和设计变量继续复用。

不整体替换已定稿的页面风格，不因出现相似代码就立即引入另一套 UI 或请求框架。

## 验证范围

新增分页参数和请求状态单元测试，并在隔离 MySQL 上检查 1001 条记录的完整遍历、跨状态排序、相同日期的稳定顺序、权限范围、末页删除和远程选料。电脑端及手机端另做浏览器验证；本地验证不代表线上验收。临时服务和数据库在验证后关闭。

2026-10-28 本地结果：556 项单元测试、13 项采购集成测试、类型检查和生产构建通过。浏览器在 1440 × 1000 与 390 × 844 下检查了深页、末页、切换每页条数、跨页勾选、远程搜索及回填、错误重试、手机筛选切换时的迟到响应和详情返回。详情返回前后均为 20 条、滚动位置 449 像素。界面检查使用隔离测试数据，失败和延迟场景使用模拟接口。

开发模式观察到 Ant Design Vue Select 自动生成 ID 的服务端渲染匹配警告（含已有全局搜索及工单选择器），本批未调整该库的 ID 策略。生产构建另行验证；主动注入的 HTTP 500 会在控制台留下预期网络错误。
