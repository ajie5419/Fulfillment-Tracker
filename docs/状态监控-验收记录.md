## 口径与推导链

1. 只监控 QMS 中未删除、未完工、未取消的工单。工件排除 `DONE`，工序排除 `DONE`，并排除已完成工件下的工序。现有模型的 `PartStatus` / `StepStatus` 没有 `CANCELLED` 枚举，取消通过工单范围排除。
2. 工件直接使用现成 `Part.statusSince`。沿用业务流程对该字段的维护，不改成工件创建时间、`updatedAt` 或工序时间。
3. 工序进入状态时间严格按 **最近一条 `FlowEvent.occurredAt` → `RouteStep.startedAt` → `RouteStep.createdAt`** 推导。数据库按工序聚合 `MAX(occurredAt)`，不按事件入库 `createdAt` 排序；只在没有事件时回退。代码注释与返回的 `sinceSource` 明确标识来源。
4. 工序时间是最近流转活动的代理口径，不是完整状态变更审计。部分报工 `REPORT`、报废 `SCRAP` 也会刷新推导时间；不筛选事件类型、不静默用 `updatedAt` 替代。异常阻塞 / 恢复如果没有新流转事件，仍按上述链取时间。
5. 天数复用 `server/services/alerts/rules.ts` 的 `shanghaiDay`、`dayDiff`：`max(0, 上海今天 - 上海进入状态日)`。跨上海零点计一天；同日为零；未来起点归零；不按满 24 小时取整。W11 衡量真实停留，按自然日**包含停工日**，与 W8 一样属于自然日规则；其他预警原有扣停工日的规则保持原口径。设置页及帮助提示明确说明此区别。
6. 统一输出实体类型 / ID、工件 ID、实体名 / 图号、工单号、状态与中文名、进入时间及来源、天数、红黄绿级别、责任人 / 部门、详情深链。
7. 工序责任人复用既有“明确负责人 → 自制班组长（有权查看工单）”解析。工件取 `currentStepId` 指向的在制工序责任人；部门沿用 QMS 部门到业务部门的映射。无法取得时返回空数组 / 空名称，界面显示 `—`，不把项目经理推定为责任人。

## 阈值与预警生命周期

- 新规则：**W11 在制状态停滞**，与原 W1–W10 并列。
- **暂定默认：黄线 7 天、红线 14 天；上线前须由用户确认。** 这是本轮采用的保守初值，并非已确认的生产 SLA。
- 继续使用 `Threshold` 表、`loadThresholds()`、设置页现有阈值表格和 `PUT /api/settings/thresholds/W11`。`remindHours = null`；黄 / 红均支持 1–365 天，红线不能小于黄线。
- `< 黄线` 正常（绿）；`>= 黄线且 < 红线` 关注（黄）；`>= 红线` 停滞（红）。相等边界归更高一级。
- 黄线只进入监控关注清单；红线进入原扫描管线，创建 `ACTIVE / RED` 预警并沿用责任人、责任部门负责人、项目经理、项目部负责人、领导的通知阶梯。不自动转异常。
- W11 活动键：`W11:<step|part>:<id>:<status>:<since毫秒>`。同一停滞周期重复扫描幂等；状态或计时起点变化使旧键退出本轮 live 集合；调大阈值后低于红线也退出 live 集合。原扫描清除逻辑将旧预警改为 `CLEARED` 并释放 `activeKey`，后续再次达红线可以重新生成。
- 状态变化后的消除由下一轮扫描完成（复用现有每 15 分钟扫描任务），不是新增即时通知通道。若新状态按约定推导链也已达红线，会消除旧周期并为新周期创建预警。
- 文案包含实体、当前状态、已停天数、工单号；长实体名优先缩短，保留状态、天数与完整工单号。

## 展示与接口选择

采用**新建接口**，不扩展原 overview 返回值：

- `GET /api/monitoring/status`：工序 / 工件分布、黄红 Top 10、阈值及计算时间。
- `GET /api/monitoring/entities`：分布下钻清单；支持 `entityType`、`status`、`page`、`pageSize`，与统计共用同一服务和范围，避免把排队工序误当成生产调度的“可开工”工序。
- 两个接口均复用领导总览权限，仅领导、项目部负责人、管理员可访问；后端校验权限。
- 基线 `app/pages/overview.vue` 已是 `/board` 跳转页。因此保留跳转，在实际项目总览 `/board` 的既有管理视图区增加 `StatusMonitoringPanel`，不恢复重复总览、不重排原有区域。`overview.vue` 注释注明入口位置。
- 数字沿用页面链接下钻方式进入 `/monitoring?entityType=…&status=…`；筛选直接由 URL 派生，同页链接和浏览器前进 / 后退同步。
- Top 10 按天数倒序，只列黄 / 红，使用 `UiSectionCard`、`UiStatCard`、`UiListItem`、`UiStatusTag`、`UiHelpTip`、`UiRefreshButton`、`UiListPager`。颜色使用既有 `done/risk/late` 语义和 `--ft-*` 变量。进入状态时间复用 `factoryDateTimeText` 显示上海时间，窄屏标签移到正文下方，保证实体与责任方可读。
- 工序详情链接 `/parts?wo=…&part=…&step=…` 打开完整工件详情并高亮确切工序，排队中的工序也能查看；定位参数通过 `useOneShotQuery` 处理后清除。工件链接打开同一详情抽屉。
- 新接口失败显示错误和重试，不显示成零计数或空清单。
